# Stained-glass bitmap assets and generation prompts

Generated with the built-in `image_gen` tool on 2026-10-25. Original creations in classic styles; not historical reproductions. Final project-bound files:

- [Magnolia](../apps/android/app/src/main/assets/glass/blossom.webp), with [outlines](../apps/android/app/src/main/assets/glass/blossom.json).
- [Iris garden](../apps/android/app/src/main/assets/glass/iris.webp), with [outlines](../apps/android/app/src/main/assets/glass/iris.json).
- [River of light](../apps/android/app/src/main/assets/glass/garden.webp), with [outlines](../apps/android/app/src/main/assets/glass/garden.json).

The generated 1536×1024 PNGs are retained as ignored local research files. `tools/stained-glass/prepare.py` converts them to 1024×683 WebP (quality 90), extracts lead-enclosed source regions at 768×512, assigns dark pixels by nearest-region growth, traces boundaries and simplifies outlines. The runtime never performs this analysis. Art-generation requests specify approximate pane counts; the actual extraction yields 79/230/264 regions, not the requested nominal counts.
